# Welcome to the MeowBot GitHub Organisation 👋

## Introduction

MeowBot is an open-source Discord music bot built with [Discord.js](https://discord.js.org/), designed to provide a seamless music listening experience directly within Discord. The project also features a dedicated web player, allowing users to interact with their music through a web-based interface.

The project consists of several key components, including the Discord bot, which handles music playback and server interactions, and the web player, which provides a user-friendly interface to control and manage music playback. These components work together to deliver an integrated music experience for Discord communities.
